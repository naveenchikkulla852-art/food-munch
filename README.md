# FoodMunch

A responsive single-page landing site for a fictional food delivery service. FoodMunch features rich UI sections like hero, features, menu filter, how-it-works, testimonials, CTA, and footer.

##  Live features
- Hero section with delivery promise and stats
- Sticky navbar + mobile hamburger menu
- Smooth section scrolling and reveal-on-scroll animations
- Meal menu with filter buttons (All, Meals, Snacks, Drinks, Desserts)
- Add to cart UI feedback (`+ Add` → `✓ Added`)
- Dynamic menu rendering from JavaScript data array
- Mobile-responsive layout and adaptive grid styles
- Scroll-to-top button and top styling transitions

## Files
- `index.html` - markup structure, section content, and script include
- `style.css` - all styles, themes, responsive media queries
- `script.js` - app logic: render menu, filter, sticky nav, mobile menu, scroll reveal
